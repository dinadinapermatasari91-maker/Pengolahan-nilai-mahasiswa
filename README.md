Program ini dibuat menggunakan bahasa C untuk membantu dosen dalam mengelola data nilai mahasiswa. Program mampu menyimpan data mahasiswa berupa NIM serta nilai Tugas, UTS, dan UAS, menampilkan seluruh data mahasiswa dalam bentuk tabel, serta menyediakan fitur untuk menambah, mengubah, dan menghapus data mahasiswa. Selain itu, program dapat menghitung rata-rata nilai tiap mahasiswa dan rata-rata nilai untuk Tugas, UTS, dan UAS, serta menampilkan mahasiswa dengan nilai rata-rata tertinggi dan terendah. Program ini juga dilengkapi dengan fitur rekursif, yaitu untuk menghitung faktorial dari jumlah mahasiswa dan menampilkan deret Fibonacci sebanyak jumlah mahasiswa. Dalam pembuatannya, program memanfaatkan array untuk menyimpan data, perulangan untuk menu dan proses perhitungan, matriks (array dua dimensi) untuk pengolahan nilai, serta fungsi rekursif untuk perhitungan faktorial dan Fibonacci.
Untuk menjalankan program ini, pastikan terlebih dahulu compiler bahasa C seperti GCC sudah terpasang di komputer. Selanjutnya, buka terminal atau Command Prompt lalu masuk ke folder tempat file program disimpan. Lakukan proses compile dengan perintah gcc nilai_mahasiswa.c -o nilai_mahasiswa. Setelah proses compile berhasil, jalankan program dengan perintah ./nilai_mahasiswa untuk pengguna Linux atau Mac, atau nilai_mahasiswa.exe untuk pengguna Windows. Setelah program berjalan, ikuti instruksi menu yang muncul di layar untuk menggunakan seluruh fitur yang tersedia.
